## A. Java 基础与集合（Day 1-2，8 题）

1. ☐ HashMap 的底层结构是什么？链表什么时候转红黑树？（两个数字都要说出来）
2. ☐ HashMap 扩容的触发条件是什么？扩容时节点怎么重新分配？（高低位拆分要讲清）
3. ☐ 为什么 HashMap 的容量必须是 2 的幂？
4. ☐ JDK7 的 HashMap 并发扩容为什么会死循环？JDK8 怎么改的？
5. ☐ ConcurrentHashMap 在 JDK7 和 JDK8 的实现分别是什么？JDK8 锁的粒度是什么？

7. ☐ 什么是 fail-fast？它是线程安全的保障吗？
8. ☐ String 为什么设计成不可变？`Integer a=127, b=127` 和 `a=128, b=128` 的 `==` 结果分别是什么，为什么？
