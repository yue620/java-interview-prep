## 模块一：Java 基础与集合（Day 1-2）

### HashMap（最高频，必须滚瓜烂熟）
- **结构**：数组 + 链表 + 红黑树（JDK8）
- **树化条件**：链表长度 ≥ 8 **且** 数组长度 ≥ 64；否则优先扩容；树退化阈值 6
- **定位**：`(n-1) & hash`（位运算代替取模，所以**容量必须是 2 的幂**）
- **扰动**：`hash = h ^ (h >>> 16)`，高低 16 位混合，减少哈希冲突
- **扩容**：超过 `容量 × 0.75` → 翻倍 → **高低位拆分**（`hash & oldCap` 为 0 留原位，为 1 去 原位+oldCap）
- **JDK7 头插法**：并发扩容链表反转 → 可能成环 → get 死循环；JDK8 改尾插
- **为什么线程不安全**：并发 put 丢数据；JDK7 还有死循环问题

### ConcurrentHashMap
- JDK7：**分段锁**（Segment，16 段各一把锁）
- JDK8：**CAS + synchronized**：空桶 CAS 插入；桶非空锁**头节点**，锁粒度 = 单个桶
- `size()` 用 baseCount + CounterCell 分散计数（类似 LongAdder 思想）

### 其他集合
- **ArrayList**：动态数组，查快（O(1)）增删慢（数组拷贝）；**LinkedList**：双向链表，实际开发几乎不用
- **fail-fast**：迭代期间结构性修改 → modCount 变化 → 抛 ConcurrentModificationException（缺陷预警，非线程安全方案）
- **equals/hashCode 契约**：equals 相等 ⇒ hashCode 必须相等；只重写 equals 会导致 HashMap 里同一个"逻辑 key"存两份
- **String 不可变**：线程安全 / 常量池共享 / hashCode 可缓存；`+` 拼接在循环里产生大量临时对象 → 用 StringBuilder（非线程安全）/StringBuffer（线程安全）
- **包装类缓存**：Integer -128~127 缓存，`==` 比较在缓存范围内为 true，超出为 false —— **比大小用 equals**

## 模块二：并发编程（Day 3-5）⭐重灾区

### 线程基础
- **创建方式**：继承 Thread / 实现 Runnable / **Callable+FutureTask（有返回值能抛异常）** / 线程池
- **run vs start**：run 是当前线程普通调用；start 才开新线程
- **sleep vs wait**：sleep 不释放锁（Thread 静态方法，哪都能用）；wait 释放锁（必须持有锁，在 synchronized 内，靠 notify/notifyAll 唤醒）

### synchronized
- **锁升级（JDK6+）**：无锁 → 偏向锁（单线程，MarkWord 记线程 ID）→ 轻量级锁（CAS 自旋）→ 重量级锁（OS 互斥量，线程阻塞）
- 目的：按竞争程度逐级加大开销，低竞争避免昂贵的重量级操作

### volatile
- **保证可见性**（写立即刷主内存，读强制从主内存读）+ **禁止指令重排**
- **不保证原子性**（i++ 是读-改-写三步）
- 经典用途：DCL 双重检查单例，防止指令重排导致拿到"半初始化对象"

### CAS 与原子类
- CAS：CPU 原子指令，比较并交换，无锁
- 问题：**ABA**（加版本号，AtomicStampedReference）、高竞争自旋耗 CPU
- **LongAdder**：高竞争下把值分散到多个 Cell，最后 sum() 求和，优于 AtomicInteger

### 线程池
- **7 参数**：核心线程数 / 最大线程数 / 空闲存活时间 / 时间单位 / 阻塞队列 / 线程工厂 / 拒绝策略
- **流程**：核心线程 → 队列 → 非核心线程（到最大）→ 拒绝策略
- **拒绝策略 4 种**：AbortPolicy（默认，抛异常）/ CallerRunsPolicy（调用者线程跑）/ DiscardPolicy（静默丢）/ DiscardOldestPolicy（丢队首）
- **为什么禁用 Executors 快捷方法**：FixedThreadPool 队列无界（OOM 风险）、CachedThreadPool 线程数无上限 —— 用 `new ThreadPoolExecutor(...)` 手动配

### ThreadLocal
- 每个线程的私有变量副本
- 内存泄漏：Thread 里的 ThreadLocalMap，**key 弱引用、value 强引用** → key 被回收后 value 泄漏 → **用完 remove()**

### 死锁
- **四条件**：互斥 / 占有且等待 / 不可剥夺 / 循环等待
- 排查：`jstack` 抓线程快照；修复：破坏循环等待（固定加锁顺序）

## 模块三：JVM（Day 6）

### 内存区域
- **线程共享**：堆（对象）、方法区（类信息/常量/静态变量）
- **线程私有**：虚拟机栈（栈帧：局部变量/返回地址）、本地方法栈、程序计数器（当前行号，线程切换恢复用）

### GC
- **判断垃圾：可达性分析**（GC Roots 出发不可达即垃圾）；不用引用计数因为**循环引用**会漏收
- **新生代复制算法**：Eden + from/to 两个 Survivor；Minor GC 把 Eden+from 存活对象复制到 to，清空 Eden+from，交换角色（对象朝生夕死，复制成本低）
- **对象晋升老年代**：年龄到 15（默认）/ 大对象直接进 / Survivor 放不下
- Minor GC（新生代）vs Full GC（整堆+方法区，慢，要尽量避免频繁发生）
- OOM 排查：`jmap -histo` 看大对象、GC 日志看回收效果

### 类加载
- **双亲委派**：先委派父加载器，父不行子才加载 → 防重复加载 + 保护核心类
- 自定义类加载器：继承 ClassLoader **重写 findClass**（别动 loadClass，那是委派流程本体）
- 你有亲手实验：Hello 在 classpath 上时被 AppClassLoader 抢走，移出 classpath 后 MyClassLoader 才加载成功

## 模块四：Spring（Day 7-8）⭐实习必考

### IoC / Bean
- IoC = 控制权交给容器；DI = 实现手段；**构造方法注入**（推荐：必填、可 final、暴露循环依赖）
- Bean 默认**单例**；无状态单例线程安全，有可变成员变量则不安全
- **生命周期**：实例化 → 属性填充 → Aware → BeanPostProcessor 前置 → @PostConstruct → BeanPostProcessor 后置（**AOP 代理在这生成**）→ 使用 → @PreDestroy 销毁
- **循环依赖三级缓存**：一级成品 / 二级半成品 / 三级对象工厂；只能解决 setter/字段注入的单例循环依赖，**构造注入无解**

### AOP
- 底层动态代理：JDK（要接口）vs **CGLIB（默认，生成子类，不能代理 final）**
- 你拿到的是代理对象 → **this 自调用绕过代理** → 一切增强失效的总根因

### 事务
- **失效五场景**：自调用 / 非 public / 异常被吞 / checked 异常（rollbackFor=Exception.class）/ 非 InnoDB
- **传播行为**：REQUIRED（默认，加入）/ REQUIRES_NEW（独立事务，保日志）/ NESTED（savepoint 子事务）

### Spring Boot
- @SpringBootApplication = @SpringBootConfiguration + **@EnableAutoConfiguration** + @ComponentScan
- **自动配置**：扫 `AutoConfiguration.imports`（Boot2 是 spring.factories）→ 条件注解过滤（@ConditionalOnClass/@ConditionalOnMissingBean）→ 注册默认 Bean，**用户定义优先**

## 模块五：MySQL（Day 9-10）⭐实习必考

### 索引
- **B+ 树**：非叶子只存索引 → 矮胖（3-4 层装千万行）→ IO 少；叶子链表相连 → 范围快
- 淘汰链：哈希（不支持范围）→ 二叉/红黑（树太高）→ B 树（非叶子存数据，更高）
- **聚簇索引**（主键，叶子=整行）vs **非聚簇**（叶子=索引列+主键）→ **回表** → **覆盖索引**（Using index）避免
- **最左前缀**：联合索引从最左列开始连续使用
- **失效场景**：列上函数/运算、隐式类型转换、like '%xx'、违反最左前缀、or 带无索引列
- **explain 看四列**：type（ALL 报警）/ key / rows / Extra（filesort、temporary 是坏信号）

### 事务与锁
- **ACID 实现**：A=undo log，D=redo log，I=MVCC+锁，C=前三者的目标
- **读现象**：脏读（未提交）/ 不可重复读（同行变，update）/ 幻读（行数变，insert/delete）
- **隔离级别**：RU < **RC**（Oracle 默认）< **RR（MySQL 默认，临键锁防幻读）** < 串行化
- **MVCC 三件套**：隐藏列（trx_id、roll_ptr）+ undo log 版本链 + ReadView
  - **RC 每次 SELECT 新 ReadView；RR 只在第一次生成复用** ← RC/RR 差异的根因
- **锁**：行锁（记录）/ 间隙锁（空隙，防插入）/ 临键锁（RR 默认单位）；**锁加在索引上，WHERE 不走索引 ≈ 锁全表**
- **乐观锁**：version 字段 / `UPDATE ... WHERE id=? AND stock>0` 原子扣减；JPA `@Version`
- **超卖方案分层**：原子 SQL → FOR UPDATE → Redis 预减 + MQ 削峰

## 模块六：Redis（Day 11）⭐实习必考

- **为什么快**：纯内存 + 单线程无锁竞争 + IO 多路复用 + 高效数据结构
- **五类型**：String（缓存/计数/锁）、Hash（对象字段）、List（队列）、Set（去重/交集）、ZSet（排行榜，跳表）
- **持久化**：RDB（快照，恢复快但可能丢数据）+ AOF（命令日志，最多丢 1s）→ 生产混合用
- **穿透**（数据不存在）：缓存空对象 / 布隆过滤器
- **击穿**（热点 key 过期）：互斥锁单线程重建 / 逻辑过期
- **雪崩**（大量 key 同过期）：过期时间加随机值 / 高可用 / 熔断
- **Cache Aside**：读先缓存后 DB 回填；写**先更 DB 再删缓存**（删除而非更新；反序有旧值回写漏洞；强一致→延迟双删/Canal）
- **分布式锁**：`SET key uuid NX PX 30000`（一条命令保证原子）→ 解锁**比对 UUID + Lua 原子删除** → 生产用 **Redisson（看门狗自动续期）**
- **内存淘汰**：`allkeys-lru`；**过期删除**：惰性 + 定期

## 模块七：场景题公式（Day 12 预习）

- **秒杀漏斗**：前端限流 → 网关限流 → Redis 预减库存（原子）→ MQ 削峰 → 匀速落库；细节：幂等（唯一索引/SETNX）、降级兜底
- **MQ**：异步/削峰/解耦；丢失三环节（confirm、持久化、手动 ack）；重复消费 → 消费端幂等
- **分布式事务**：默认答最终一致（本地消息表 / MQ 事务消息），强一致提 TCC/Seata
