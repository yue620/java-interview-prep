# java-interview-prep

Java 后端实习面试准备仓库（2026/8/10 – 8/28）。

每天的学习代码和笔记都会提交到这里，作为面试时的实践证据。

## 目录结构

| 目录 | 内容 | 对应阶段 |
|---|---|---|
| `collection/` | 手写 MyHashMap、线程不安全复现实验等 | 阶段 1：Java 基础 + 集合（8/10–8/13） |
| `concurrency/` | 死锁实验、手写线程池、DCL 单例等 | 阶段 2：并发编程（8/14–8/17） |
| `jvm/` | OOM 复现、GC 日志实验、自定义 ClassLoader | 阶段 3：JVM（8/18–8/19） |
| `mini-mall/` | Spring Boot 实战项目（缓存/事务/锁/MQ） | 阶段 4：Spring+MySQL+Redis（8/20–8/23） |
| `notes/` | 每日打卡、错题本 | 全程 |

## 学习原则

每道八股题走四步：**看题 → 先自己口述 → 动手写代码验证 → 对照标准答案**。

完整计划见 `../java八股学习计划.md`
